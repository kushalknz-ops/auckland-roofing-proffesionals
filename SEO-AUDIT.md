# SEO metadata audit

8 November 2026, Auckland time

The audit covers all 32 canonical pages in the generated sitemap, plus the utility pages and representative aliases and errors. Each row records the title and description received over HTTP from the local production build with JavaScript disabled and a Googlebot user agent.

Every sitemap URL returned HTTP 200 with exactly one title, description and canonical. Titles and descriptions are unique across those URLs and meet the 50–60 and 150–160 character targets. Open Graph and Twitter titles and descriptions match. The robots file permits search crawler access to the audited pages.

## Remaining issues and verification limits

- Production verification remains open. The public domain could not be reached from this environment and the changes are in the working checkout.
- The main, legal and service pages serve their metadata in the initial HTML. Their page copy still requires JavaScript. The blog and case studies include their page copy in the initial HTML.
- Cloudflare Pages and Workers service routing passed local handler tests with simulated asset storage. Other hosting configurations have not been exercised in their native runtimes. Netlify’s query rewrite matches the canonical service query by itself. A service URL with extra tracking parameters can receive the default service tags before JavaScript runs. [Netlify query matching rules](https://docs.netlify.com/manage/routing/redirects/redirect-options/#query-parameters)
- Google can choose a different title link or snippet based on the search and page content. [Title link guidance](https://developers.google.com/search/docs/appearance/title-link), [snippet guidance](https://developers.google.com/search/docs/appearance/snippet)
