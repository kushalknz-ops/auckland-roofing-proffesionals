# Auckland Roof Professionals

<!-- impeccable:product-schema 1 -->

## Platform
Web. Existing React, TypeScript and Vite application.

## Purpose and audience
The existing website presents commercial, industrial and residential roofing services in Auckland. Visitors explore services and projects before making an enquiry through the existing contact form or quote flow.

## Confirmed constraints
- Preserve the existing branding, typography, colours, animations and unrelated website functionality.
- Give all five projects in the homepage carousel their own case study URL and connect every card to its page.
- Use the existing project summaries and assets. Missing project records must be clearly labelled placeholders; never invent client feedback, results, dates or site challenges.
- The user confirmed roofing journey stages: consultation, planning, design/specification, installation, quality checks and handover.
- Support desktop, tablet, mobile, keyboard navigation, reduced motion and search indexing.

## Evidence limits
The repository contains a short summary, duration, scope and image reference for each of the five projects. Detailed client briefs, dated milestones, inspection records, attributable testimonials and measured outcomes are not provided. Two carousel entries reuse general service images. Existing portfolio copy is source material, not independent verification.
